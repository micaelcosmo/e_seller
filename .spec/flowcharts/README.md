# .spec/flowcharts/

Trilha **viva** de **fluxogramas** (obrigatórios) do e_seller, em Mermaid (renderiza no
VSCode/GitHub). Mantida atualizada a cada mudança relevante de fluxo.

## Diagramas

| Doc | Fluxo |
|---|---|
| [`development.md`](development.md) | Processo de desenvolvimento (SDD → TDD → deploy). |
| [`backend.md`](backend.md) | Arquitetura/fluxo de uma requisição no backend. |
| [`frontend.md`](frontend.md) | Arquitetura/fluxo do frontend (Next.js). |
| [`navigation-client.md`](navigation-client.md) | Navegação do cliente (comprador). |
| [`navigation-admin.md`](navigation-admin.md) | Navegação do vendedor/admin. |

## Regra de manutenção

Atualizar o fluxograma correspondente sempre que o fluxo mudar e registrar em
[`CHANGELOG.md`](CHANGELOG.md).
